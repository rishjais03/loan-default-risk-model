# Results Summary

## Model Performance

The logistic regression credit risk model achieved strong predictive performance on the borrower default classification task.

### Performance Metrics

| Metric | Value |
|---|---|
| Accuracy | 83.83% |
| ROC-AUC Score | 0.8415 |

The ROC-AUC score above 0.84 indicates strong classification capability in distinguishing default and non-default borrowers.

## Expected Loss Estimation

The project estimated Expected Loss (EL) using:

Expected Loss = Probability of Default × Loss Given Default × Exposure at Default

### Assumptions

| Assumption | Value |
|---|---|
| Recovery Rate | 10% |
| Loss Given Default (LGD) | 90% |
| Exposure at Default (EAD) | Loan Amount |

Example expected loss estimates generated by the model:

| PD | EAD | Expected Loss |
|---|---|---|
| 0.8269 | 7000 | 5209.30 |
| 0.2018 | 5000 | 908.27 |
| 0.1572 | 5600 | 792.17 |

## Modeling Assumptions

The analysis relies on several simplifying assumptions commonly used in introductory credit risk modeling frameworks.

### Statistical Assumptions

- Logistic regression appropriately captures the relationship between borrower characteristics and default probability.
- Historical borrower behavior is assumed to be representative of future borrower risk behavior.
- Borrower observations are treated as independent records.

### Data Assumptions

- Missing observations were removed during preprocessing.
- Categorical variables were encoded numerically for model estimation.
- The dataset is assumed to be sufficiently representative for demonstrating a prototype credit risk model.

---

## Limitations

This project represents a baseline credit risk modeling framework and does not include:

- Macroeconomic stress testing
- Advanced ensemble machine learning models
- Time-varying borrower behavior
- Regulatory capital modeling
- Portfolio optimization techniques

The project is intended for educational and research purposes focused on demonstrating practical applications of predictive analytics in financial risk management.
