# Loan Default Risk Model

## Overview

This repository contains a credit risk analytics and probability of default (PD) estimation framework developed using borrower-level financial data and machine learning techniques.

The project focuses on predicting loan default probabilities and estimating expected losses using borrower characteristics such as income, loan balances, debt obligations, and historical default behavior.

---

## Research Objective

The objective of this project is to:

- Predict the probability of borrower default
- Estimate expected credit losses
- Analyze borrower risk characteristics
- Develop a quantitative credit risk modeling workflow

The analysis applies statistical and machine learning techniques commonly used in financial risk management and banking analytics.

---

## Methodology

The project includes:

- Data cleaning and preprocessing
- Exploratory data analysis
- Probability of Default (PD) estimation
- Logistic regression modeling
- Model evaluation and validation
- Expected loss estimation

---

## Datasets Used

The dataset contains borrower-level information including:

- Income
- Total loans outstanding
- Debt-related metrics
- Historical default status
- Borrower financial characteristics
